# ViraCheck — Website

ViraCheck iOS uygulamasının tanıtım sitesi ve yasal belgeleri. GitHub Pages ile
[egesey.github.io/viracheck](https://egesey.github.io/viracheck/) adresinde yayınlanır.

Marketing site and legal documents for the ViraCheck iOS app, published via
GitHub Pages at [egesey.github.io/viracheck](https://egesey.github.io/viracheck/).

Ekran görüntüleri `screens/` altındadır ve iOS simülatöründen alınmıştır.
Screenshots live under `screens/` and are captured from the iOS simulator.

Bu repo yalnızca siteyi içerir; uygulama kaynak kodu ayrı ve özeldir
(`egesey/viracheck-app`).

This repository contains only the website; the app source code is separate and
private (`egesey/viracheck-app`).

> **Dikkat / Note:** Repo adı değişirse Pages adresi de değişir ve GitHub eski
> yolu **yönlendirmez**. Adı değiştirirsen uygulamadaki `src/lib/links.ts`
> dosyasını ve App Store Connect'teki URL'leri birlikte güncelle.
>
> Renaming this repository changes the Pages URL, and GitHub does **not**
> redirect the old published path. If you rename it, update `src/lib/links.ts`
> in the app and the URLs in App Store Connect at the same time.
